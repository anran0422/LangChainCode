ChatPromptTemplate.from_messages() 可以去构造对话类型提示词模版
ChatPromptTemplate() 也可以

但是 ChatPromptTemplate.from_template() 不可以
想来是对话式，并不是简单的 PromptTemplate.from_template()
```
template = ChatPromptTemplate(
    [
        {"role": "system", "content": "请用中文取描述一下这张图片"},
        {"role": "user", "content": [{"img_url": "{img_url}"}]}
    ]
)
```
```
template = ChatPromptTemplate.from_messages(
    [
        {"role": "system", "content": "请用中文取描述一下这张图片"},
        {"role": "user", "content": [{"img_url": "{img_url}"}]}
    ]
)
```

在前面 PromptTemplate

使用 PromptTemplate.from_template() 去构造提示词模版

PromptTemplate() 也可以
```
template = PromptTemplate(
    template="请评价 {product} 的优缺点，包含 {aspect1}和{aspect2} 两个方面",
    input_variables=["product", "aspect1", "aspect2"]
)
```
```
template = PromptTemplate.from_template("请给我一个关于 {topic} 的 {type} 解释。")
```
